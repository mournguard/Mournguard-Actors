# Mournguard Actors
Actors for the Mournguard ECS system.

Includes highly customizable three part action system (Object, Subject, Verb) and allows Components to provide possible actions to their Entity.

# Requires
- [![Mournguard-ECS](https://img.shields.io/badge/Mournguard-ECS-blue?logo=github)](https://github.com/mournguard/Mournguard-ECS)
	- `git submodule add -- git@github.com:mournguard/Mournguard-ECS.git .\addons\Mournguard-ECS`
